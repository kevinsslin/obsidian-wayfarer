# 0.1.9: browse stops, and choose your Google language

## Behavior

The map has one selection. Its compact navigator shows that place with Previous, Navigate and Next stop. Date selection chooses the first stop of that day; pin/list selection and previous/next browsing select a place directly. Previous and Next cross day boundaries and are disabled at the start/end. Navigate opens directions to the selected place. No separate current-trip marker, start/finish workflow, reset menu or progress storage is used. Old local progress records are left untouched and ignored.

On narrow panes, Map / List use recognizable icons with accessible names, selected styling and 44px targets. The list hides the navigator. Returning from the list recalculates footer clearance before opening details, so the popup fits around the header and navigator even at larger text sizes. Desktop day chips and floating timeline remain.

Google results default to automatic language: an explicit Wayfarer interface preference wins, otherwise use Obsidian's original locale. Japanese Obsidian therefore requests Japanese Google content even though Wayfarer's untranslated map UI falls back to English. Users can independently choose a Google language, including custom codes. Invalid locale syntax falls back to English; valid codes still need to be supported by Google.

Existing saved language codes are preserved. Earlier versions persisted the `zh-TW` default without recording whether the user chose it, so upgrades cannot safely distinguish default from preference. Choose Follow interface language to opt in. Existing note metadata and provider tile labels are not translated.

## Validation

- `pnpm check`: lint, CSS lint, typecheck, 115 tests in 12 files, production build and load smoke.
- Language tests cover automatic English/Japanese/French/German/Korean, explicit overrides, Chinese locale normalization, regional codes, empty values and malformed values.
- Built-plugin smoke intercepts Places search, Places details and Routes requests and asserts the resolved language reaches all three. It also tests upgrade preservation and opting into automatic language without calling live Google services.
- The real Obsidian settings renderer was exercised with saving intercepted: automatic mode hides the custom field, Japanese resolves to `ja`, and a custom `pt-BR` value remains effective when switching away and back. Existing preferences were restored.
- Real Obsidian renderer checks exercise Previous / Next, day changes, selected-place navigation URLs, pin/list selection, disabled endpoint controls, untouched legacy progress storage and reload.
- Layout checks cover 390/320px panes, floating/hidden/docked mobile navigation, an overlapping header, larger text, list scroll reachability and popup bounds in English and Traditional Chinese.
