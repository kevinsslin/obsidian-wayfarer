# 0.1.6 verification

The desktop retains the existing date chips, floating timeline, stop cards and theme colors. Narrow panes use a single date selector and map/list buttons over the full map content area. Current trip starts collapsed; previous, navigation and next are separate actions.

## Automated checks

`pnpm check`: ESLint, stylelint, TypeScript, 98 tests in 10 files, production build and bundle load smoke passed locally.

`node scripts/journey-smoke.mjs`: passed against Obsidian 1.13.7 with the repository's Japan 2026 test fixture. It verifies:

- Start at a selected stop; Previous is disabled at the first stop.
- Previous and Next move manually in note order, including both directions across a date boundary.
- Browsing a different day preserves progress; Back to current stop restores the day and camera.
- Navigation produces a Google Maps destination URL with no origin, leaving progress unchanged. The external open is intercepted for this check.
- Progress persists across disabling/re-enabling the plugin.
- Finishing the last stop removes the next navigation action.
- At 390×844 and 320×640, the map fills the pane; controls fit and have at least 44 px touch targets; the current pin is clear of the floating controls.
- The list fits above the progress card; selecting a stop returns to the map without changing progress or replacing the source note.
- Place popups fit both phone widths; the narrow map's zoom controls hide while a popup is open.

Pure tests also cover repeated visits, inserted lines, removed/ambiguous stops, malformed saved references, Google Maps URLs and itinerary parsing. [Geometry and action receipts](0.1.6-receipts.json).

## Boundaries

Manual progress is local to this device and keyed by note path. It does not change the Markdown plan or track GPS. Renaming a note requires selecting the current stop again. Actual external-app navigation and native iOS/Android behavior remain unverified. Research proposals for route invalidation, offline basemaps and broader UI restructuring are not part of this release.
