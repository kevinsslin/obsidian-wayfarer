# 0.1.7: phone host layout and reading UX

## Problem and choices

The user's iPhone screenshots showed two collisions that isolated pane tests missed: CSS `env(safe-area-inset-top)` pushed the date bar down again even below the host header; an independent 66 px zoom offset then placed zoom underneath it. The progress card only accounted for the home indicator and was covered by Obsidian's floating navbar.

The view now measures visible host header/navbar/keyboard toolbar rectangles relative to its content area. It only reserves the portions that intersect the pane. Resize, viewport, host attribute, layout and transition changes refresh those measurements; listeners and observers are disposed with the view. The date bar sits 8 px below the available top edge. Zoom and list positions derive from its measured bottom; the progress card clears the actual navbar top by 10 px. The source is Obsidian 1.13.7's host `.view-header`, `.mobile-navbar`, `.mobile-toolbar` styling and the supplied phone screenshots.

On narrow panes, Map and List are now text labels. List becomes an opaque, scrollable reading surface, with the current progress collapsed into one row. Expanding progress returns to the map and closes the list. Transport legs are plain mode/time/distance information; change transport is an explicit action in place details. Missing-key setup prompts no longer repeat through the phone list, and unrouted distances are explicitly labelled straight-line distances. Desktop date chips and floating timeline retain their original behavior.

## Verification

`pnpm check`: lint, CSS lint, TypeScript, **102 tests in 11 files**, build and bundle smoke passed locally. Four new geometry tests distinguish static vs overlapping headers, docked vs overlapping footers, hidden nav, keyboard viewport and disjoint panes.

`node scripts/journey-smoke.mjs /tmp/wayfarer-0.1.7-host-qa` passed against the real plugin renderer. In addition to previous/next/navigation/progress-reload checks, it reconstructs host chrome using Obsidian's mobile CSS and verifies:

- 402×874 floating navbar, hidden navbar, and overlapping header configurations.
- 390×844 docked-navbar configuration.
- 320×740 with 20 px host text size.
- Date bar at the available top edge; zoom at least 8 px below it.
- Collapsed and expanded progress at least 8 px above the visible navbar; no horizontal button overflow.
- List below the date selector and above collapsed progress, no transport edit buttons, hidden map while reading, last stop scrollable into view.
- Place detail popups below the selector and above progress in all five host scenarios.
